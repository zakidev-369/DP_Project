# Prototype demonstration

Open prototype/index.html in a browser. It requires no installation or network connection. It demonstrates target entry, progress, highlighted evidence, review decisions, filtering and JSON export using synthetic examples.

The interface labels all example findings and scores as illustrative. It does not fetch URLs, run an AI model or establish detection accuracy.


- Choose the fictional shop, run the demonstration and inspect confirmshaming and urgency cues.
- Dismiss a finding with a note, filter review state and export the JSON result.
- Choose the neutral fixture and inspect the qualified no-supported-cues message.
- Choose the capture-failure fixture and demonstrate recovery.
- Use the demonstration to gather real feedback on wording and evidence requirements.
- Backend capture, model training and persistent server storage remain implementation work.
