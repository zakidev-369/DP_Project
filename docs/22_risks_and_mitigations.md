# Risks and mitigations



| Risk | Likelihood / impact | Response | Owner |
| --- | --- | --- | --- |
| Missing user or supervisor evidence | High / high | Keep pending and obtain real dated records. | Both |
| Small or ambiguous dataset | High / high | 50-region pilot, independent review and scope reduction if necessary. | Akbar |
| Website leakage | Medium / high | Deduplicate and group by domain/template before splitting. | Akbar |
| Unsafe page requests | Medium / high | Allowlist, request checks, isolated worker and network egress policy. | Zaki |
| Capture mismatch | Medium / medium | Fixed viewport, browser metadata and coordinate tests. | Zaki |
| Compute or time constraints | Medium / high | Fixed encoders and small heads; defer optional features. | Akbar |
| Overstated model conclusions | Medium / high | Suspected-cue wording, evidence and human review. | Both |
| Sensitive material in public Git | Medium / high | Private raw data; publish only permitted anonymised summaries. | Both |
| Unknown final deadline | Medium / high | Confirm university schedule and revise dates. | Both |
