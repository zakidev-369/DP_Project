# Project proposal

Development of a Multimodal AI System for Detecting Deceptive Design Patterns in Web Applications

Zaki Sadaqatzada, SE-2402, and Akbar Khalili, SE-2409. Software Engineering. Supervisor: Ахметжанова Шынар Егеубаевна. Submission date: 24 October 2026.

The project proposes a web application that helps designers, developers and QA reviewers inspect suspected deceptive interface patterns. It will combine screenshots, visible text and Document Object Model features, then show evidence behind each flag for human review.

The aim is to implement and evaluate a bounded multimodal review workflow, comparing it with text-only and image-only alternatives on websites excluded from training. A gain from combining modalities is a research question, not an assumed result.

The October submission comprises analysis, design, an offline demonstration and an evaluation plan. Dataset collection, trained-model results and a working capture service are later deliverables.
