# Literature review and research gap

Twelve research sources inform the design: eleven identified conference or journal publications and one clearly labelled preprint. Ten date from 2022 onward. The 2019 study and 2021 conceptual analysis are retained as foundations. Source pages were checked on 23 October 2026.

Definitions precede models. The conceptual analysis [R02] and ontology [R03] support a small operational label guide that separates visible cues from motive. Overlapping concepts justify multi-label annotation and an uncertainty state.

Text baselines provide a reproducible reference [R06]. Screenshot and UI-property approaches [R04, R05] motivate image localisation and feature extraction. This project will compare models on identical grouped splits rather than rank metrics reported on incompatible datasets.

Newer multimodal work [R09] prevents novelty claims based only on combining images and text. The proposed contribution links screenshot evidence, DOM features, model versions and reviewer decisions in a narrow web workflow.

Coverage remains uneven [R07, R08]. Account disabling and cancellation [R10, R12] depend on sequences that one screenshot cannot capture. Those behaviours remain outside scope. Highlighting tools [R11] motivate separate evaluation of reviewer usefulness.

This is a targeted review, not an exhaustive systematic review. Searches covered definitions, datasets, screenshot recognition, multimodal detection and interaction-dependent limitations. The tables show each source’s approach, limitations and concrete use.
