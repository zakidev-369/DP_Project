# Publication analysis 1



| Source | Approach | Limitation and use |
| --- | --- | --- |
| R01 Mathur et al.<br>2019<br>PACM HCI, CSCW | Large web crawl with expert categorisation. | Shopping and text emphasis restrict transfer to visual patterns. Foundation for urgency and confirmshaming labels, not current prevalence. |
| R02 Mathur, Mayer and Kshirsagar<br>2021<br>CHI 2021 | Connects interface attributes with different concepts of harm. | A conceptual framework does not provide classifier ground truth. Separate visible cues from conclusions about motive or wrongdoing. |
| R03 Gray, Bielova, Santos and Mildner<br>2024<br>CHI 2024 | Harmonises ten taxonomies into 64 types at three levels. | Broad concepts need operational annotation rules. Map four project labels to established concepts and document overlaps. |
| R04 Mansur, Salma, Awofisayo and Moran<br>2023<br>ICSE 2023 | Combines visual and text cues for screenshot detection and localisation. | Performance varies across types and benchmark coverage is limited. Return region evidence and report class-level results. |
