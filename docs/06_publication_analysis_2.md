# Publication analysis 2



| Source | Approach | Limitation and use |
| --- | --- | --- |
| R05 Chen et al.<br>2023<br>UIST 2023; manuscript revised 2024 | UIGuard extracts UI properties and applies knowledge-driven checks. | Mobile results do not establish website performance. Use property features and benign examples, then validate on web domains. |
| R06 Yada et al.<br>2022<br>IEEE BigData 2022 | Adds negative text examples and compares language models. | Text cannot represent purely visual choice imbalance. Include text-only baselines and explicit benign examples. |
| R07 Soe, Santos and Slavkovik<br>2022<br>Research preprint; publication status unconfirmed | Studies engineered features and a classifier for cookie banners. | Narrow context and annotation ambiguity limit transfer. Keep uncertainty and adjudication in the label protocol. |
| R08 Nie, Zhao, Li, Luo and Liu<br>2024<br>PACM Software Engineering, FSE | Reviews taxonomies, tools and datasets. | Detection coverage and available data remain uneven. Distinguish unsupported categories from negative findings. |
